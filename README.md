Text Analysis Using Python
Project Overview

This project analyzes a given text and calculates:

Total number of words
Total number of characters
Total number of vowels
Repeated words and their frequency
Features
Word Count
Character Count
Vowel Count
Repeated Word Detection
Technologies Used
Python 3
Sample Input

python is easy and python is powerful

Sample Output

Word Count: 7

Character Count: 37

Vowel Count: 12

Repeated Words: {'python': 2, 'is': 2}

Learning Outcomes
Basic Text Processing
Word Tokenization
Character Counting
Vowel Analysis
Repeated Word Detection
Introduction to NLP
